**BookNest
**
BookNest is a simple and responsive online bookstore developed using HTML, CSS, and JavaScript. It provides a user-friendly platform to explore books from different categories, view book details, manage a shopping cart, and place demo orders.

This is my first web development project, created to apply my frontend development knowledge and gain practical experience in building a complete website.

Features

Homepage: Displays featured books and book categories.

Book Catalogue: Browse books with search, category filters, and sorting options.

Book Details: View book information, author, price, and ratings.

Shopping Cart: Add books, update quantities, and remove items.

Wishlist: Save favourite books for later.

Checkout: Complete a demo checkout process.

User Authentication: Demo login and registration pages.

Order History: View previously placed demo orders.

Admin Panel: Add and delete books from the catalogue.

Responsive Design: Supports desktops, laptops, tablets, and mobile phones.

Technologies Used

HTML5

CSS3

JavaScript

LocalStorage
**Live Demo Link:** https://booknest07.vercel.app

**Important Note**

BookNest is currently a frontend-only demonstration project. It uses browser LocalStorage to store books, cart items, wishlist items, user information, and orders.

No backend or database is connected.

Login and registration are demonstration features, not secure authentication.

Payments are simulated; no real transactions are processed.

The admin panel is for demonstration purposes and is not protected.
